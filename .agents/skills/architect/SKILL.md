Design for the target stated in the task. For a Python CLI, specify the entry point, main functions, data representation, error behavior, and testable contracts using Python 3.11 standard library. For a browser app, specify the HTML structure, CSS layout, JavaScript state and events, game rules, accessibility, and pure logic that Node can test. Browser apps use plain HTML, CSS, and JavaScript without external packages or network resources. Keep the design proportionate to the request. Return a Markdown architecture brief for Developer and QA. Do not execute commands or modify files.
